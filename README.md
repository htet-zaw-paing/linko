### What Linko Can Do
* **Download Audio:** Convert web links into MP3 files with cover art.
* **Save Videos:** Download TikToks, Instagram Reels, and YouTube Shorts in clean MP4 format (watermark-free).
* **Music Recognition (Shazam):** Identify songs from voice recordings or forwarded audio clips.
* **Search Music:** Search YouTube directly inside Telegram.
* **View Lyrics:** Fetch full song lyrics instantly in the chat.
* **Voice Notes:** Turn any audio link into a playable Telegram voice memo.
* **Trending Charts:** Check the global top 10 songs and download them with one tap.

### How to Use

**1. Download Media from a Link**
Paste a public link (YouTube, TikTok, Instagram) into the chat. Choose your format:
* <kbd>Video (MP4)</kbd> - Watermark-free video.
* <kbd>Standard (128 kbps)</kbd> - Saves mobile data.
* <kbd>High (320 kbps)</kbd> - Best sound quality.
* <kbd>Voice Note (OGG)</kbd> - Telegram voice memo.

**2. Identify a Song (Shazam)**
Hold the Telegram microphone icon, record 5-10 seconds of music playing around you, and send it. Linko will identify it and provide a <kbd>Download This Song</kbd> button.

**3. Read Song Lyrics**
After downloading a track, tap the <kbd>View Lyrics</kbd> button attached beneath the audio file to read the lyrics in the chat.

### Command Reference

| Command | Action |
| :--- | :--- |
| `/start` | Restart the bot and view the welcome guide |
| `/search [name]` | Find songs directly inside Telegram |
| `/trending` | View the top 10 songs on global music charts |
| `/help` | Open the quick help guide |
| `/quality` | View bitrate comparisons and file sizes |
| `/terms` | View copyright, fair-use, and privacy policies |
| `/about` | View information about Linko |

> **Platform Limits:**
> * Maximum media length: **30 minutes**.
> * Maximum file size: **50 MB**.
> * Processes public links only (no private accounts or paywalls).

### Linko ဘာတွေလုပ်ပေးနိုင်လဲ
* **သီချင်းဒေါင်းမယ်:** YouTube ကလင့်ခ်တွေကို Cover ပုံလေးတွေနဲ့ MP3 အဖြစ်ပြောင်းပေးပါတယ်။
* **ဗီဒီယိုဒေါင်းမယ်:** TikTok, IG Reels နဲ့ Shorts တွေကို ရေစာ (Watermark) မပါဘဲ အကြည်ဒေါင်းလို့ရပါတယ်။
* **သီချင်းရှာမယ် (Shazam):** နာမည်မသိတဲ့သီချင်းတွေကို အသံဖမ်းပို့လိုက်ရုံနဲ့ ရှာပေးပါတယ်။
* **စာသား (Lyrics) ဖတ်မယ်:** သီချင်းဒေါင်းပြီးရင် သီချင်းစာသားတွေကို Chat ထဲမှာတင် တန်းဖတ်လို့ရပါတယ်။
* **Voice Note ပြောင်းမယ်:** သီချင်းလင့်ခ်တွေကို Telegram Voice Note အဖြစ် ပြောင်းပေးပါတယ်။
* **Trending:** ကမ္ဘာတစ်ဝှမ်း နာမည်ကြီးနေတဲ့ Top 10 သီချင်းတွေကို ကြည့်ပြီး တစ်ချက်နှိပ်ရုံနဲ့ ဒေါင်းနိုင်ပါတယ်။

### ဘယ်လိုသုံးရမလဲ

**၁။ လင့်ခ်ကနေ ဒေါင်းရန်**
YouTube, TikTok သို့မဟုတ် IG က လင့်ခ်တစ်ခုကို ကူးပြီး Linko ဆီပို့လိုက်ပါ။ ပြီးရင် လိုချင်တဲ့ Format ကိုရွေးပါ-
* <kbd>Video (MP4)</kbd> - Watermark မပါတဲ့ ဗီဒီယို။
* <kbd>Standard (128 kbps)</kbd> - ဖုန်းဘေလ်သက်သာတဲ့ ဆိုဒ်အသေး။
* <kbd>High (320 kbps)</kbd> - အသံထွက်အကောင်းဆုံး Quality။
* <kbd>Voice Note (OGG)</kbd> - Telegram Voice Record ပုံစံ။

**၂။ သီချင်းနာမည်ရှာရန် (Shazam)**
အပြင်မှာဖွင့်ထားတဲ့ သီချင်းကို Telegram ကနေ (၅) စက္ကန့်လောက် အသံဖမ်း (Voice Record) ပြီး ပို့လိုက်ပါ။ Linko က ဘာသီချင်းလဲဆိုတာ ရှာပေးပြီး <kbd>Download This Song</kbd> ဆိုတဲ့ ခလုတ်လေး ချပေးပါလိမ့်မယ်။

**၃။ သီချင်းစာသား (Lyrics) ဖတ်ရန်**
သီချင်းဒေါင်းပြီးတာနဲ့ အောက်မှာပေါ်လာတဲ့ <kbd>View Lyrics</kbd> ခလုတ်ကို နှိပ်ပြီး စာသားတွေကို ဖတ်နိုင်ပါတယ်။
